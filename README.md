# Penetration-Home-Lab

A comprehensive, enterprise-isolated penetration testing home lab featuring Kali Linux (Attacker), alongside Windows 10, Metasploitable 2, and Genymotion Android environments (Victims).
This repository documents the step-by-step architecture setup, tool integration, and practical vulnerability write-ups spanning from foundational scanning to advanced exploitation methodologies.
